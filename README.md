# WhisperSafe — Anonymous Reporting + Secure Follow-Up

WhisperSafe is a privacy-first anonymous reporting platform with Tracking ID follow-up, end-to-end encrypted storage, admin triage console, and encrypted file attachments.

## Features
- Anonymous report submission (no user accounts)
- Tracking ID based follow-up thread
- Encrypted message storage (AES-GCM)
- Admin authentication + protected routes
- Admin Command Center (filters, sorting, quick open)
- Smart triage queue (priority scoring + SLA view)
- Risk signals + threat meter
- Encrypted attachments (reporter upload, admin-only download)
- Modern landing page UI + scroll reveal

## Tech Stack
- Next.js (App Router)
- Prisma ORM
- SQLite (dev)
- Node.js runtime
